How to get Plaid keys (5 minutes)
  1. Create a free account at dashboard.plaid.com (choose "I'm a developer / building for my own business").
  2. Open Team Settings → Keys. Copy the client_id and the Sandbox secret into the fields above, leave the environment on Sandbox, save.
  3. Go to Banking → Connect a bank and link Plaid's test bank with user user_good / password pass_good to see the flow end to end.
  4. In the Plaid dashboard request Production access (Transactions product only). Approval for a small business usually takes a day or two.
  5. Paste the Production secret here, switch the environment to Production, save, then connect your real Chase (or any) login.

The same values can live in .env as PLAID_CLIENT_ID, PLAID_SECRET, PLAID_ENV; what you enter here wins. Set PUBLIC_BASE_URL{% if public_base_url %} (currently {{ public_base_url }}){% endif %} so the Plaid Link redirect and email links point at this server. Full walkthrough, bank-by-bank CSV export steps and troubleshooting: docs/BANK_CONNECTIONS.md in the install folder.
